# دفتر ایجنت‌ها (Agent Office)

Agent Office محیطی دیداری برای راه‌اندازی و هماهنگی ایجنت‌های کدنویسی است. می‌توانید ایجنت‌ها را در تیم‌های جداگانه بنشانید، کارهایشان را ببینید، به آن‌ها پیام بدهید و جلسه برگزار کنید.

## شروع سریع

پیش‌نیازها: Node.js نسخهٔ ۲۰ یا بالاتر، Git و دست‌کم یکی از ابزارهای ایجنت مانند Codex، Claude Code یا OpenCode که روی رایانه نصب و وارد حساب شده باشد.

```bash
npm install -g agent-office
agent-office /path/to/project --agent codex
```

آدرس دفتر در خروجی ترمینال نشان داده می‌شود. بار اول، گذرواژهٔ مدیر را همان‌جا یادداشت کنید و آن را فقط با اعضایی که می‌خواهید دعوت کنید به‌اشتراک بگذارید.

## کارهای روزانه

- از منوی دفتر، تیم یا پروژهٔ موردنظر را انتخاب کنید.
- برای افزودن ایجنت، تسک تازه بسازید یا یک تسک را به صف بسپارید.
- روی ایجنت کلیک کنید تا گفت‌وگو، ترمینال و وضعیت کارش را ببینید.
- از بخش جلسه، چند ایجنت را برای همکاری روی یک کار دعوت کنید.
- در نمایش دوبعدی، فهرست ایجنت‌ها و کنترل‌های اصلی را در صفحه‌ای سبک‌تر ببینید.

## انتخاب ارائه‌دهنده

نام ابزارها، مدل‌ها و دستورهای ترمینال به زبان اصلی نمایش داده می‌شوند تا با تنظیمات واقعی نرم‌افزار هماهنگ بمانند. برای تغییر ارائه‌دهنده یا مدل پیش‌فرض، بخش «تنظیمات» را باز کنید.

برای راهنمای کامل نصب، تنظیمات و قابلیت‌ها، [README انگلیسی](README.md) و مستندات پروژه را ببینید.
